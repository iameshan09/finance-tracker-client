# Finance Tracker

This is a web application designed to help users manage their income and expenses efficiently through intuitive tracking and reporting features.

## Technology Choices & Reasoning

| Technology               | Reason                                                                               |
|--------------------------|--------------------------------------------------------------------------------------|
| **Blazor Server**        | Blazor Server works with browsers that don't support WebAssembly.                    |
| **MudBlazor**            | modern UI components, strong community support, and seamless integration with Blazor |
| **Visual Studio 2022**   | Rich development environment with strong support for .NET.                           |


---

## Architecture

- Monolithic layered structure
---

## 🛠 Prerequisites

- [.NET 8.0 SDK]
- Git
- (Optional) Visual Studio 2022+ / VS Code with C# extensions
